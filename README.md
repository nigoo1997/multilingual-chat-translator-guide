# PolyChat 多语言聊天翻译助手

一个不依赖第三方翻译扩展的 Chromium 浏览器扩展。它使用你自己的 OpenAI 兼容 API，在 Facebook 和 Messenger 中提供页面双语翻译，以及“中文草稿 → 自然外语回复”的独立助手。

兼容 Microsoft Edge 和 Google Chrome。

## 核心能力

- 自动识别动态加载的聊天、评论和帖子，在原文旁显示简体中文译文。
- 在网页右侧打开独立回复面板，保留中文草稿和外语结果。
- 支持自然口语、亲切友好、礼貌尊重和专业简洁四种语气。
- 一键复制译文，或把译文填入最近使用的聊天输入框。
- 只填入草稿，不点击发送按钮。
- API 地址、模型、鉴权方式和额外请求头均可配置。
- API Key 只存放在浏览器扩展的本地存储中，不会写入仓库。
- 页面译文缓存在扩展后台进程内，减少重复 API 请求。

## 配置自己的 API

安装后点击扩展图标，再点击「API 设置」。至少填写：

| 配置项 | 示例 |
| --- | --- |
| API Base URL | `https://api.example.com/v1` |
| 协议 | `OpenAI Chat Completions` |
| 模型名称 | `your-model-name` |
| 鉴权方式 | `Authorization: Bearer` |
| API Key | 由你的 API 服务提供 |

如果填写的是 Base URL，扩展会根据协议自动补全：

```text
/chat/completions
```

或：

```text
/responses
```

也可以直接填写完整 Endpoint。非标准接口可通过「额外请求头」补充工作区或租户信息。

点击「保存并测试」后，扩展会请求一次非敏感测试文本。首次保存某个 API 域名时，浏览器会要求授予该域名的访问权限。

> 当前适配器要求接口兼容 OpenAI Chat Completions 或 Responses 的请求和返回格式。如果你们的 API 契约不同，只需修改 `src/background.js` 中的 `buildRequestBody()` 和 `extractResponseText()`。

## 使用方式

### 阅读外语内容

1. 打开 Facebook 或 Messenger。
2. 点击扩展图标，开启「页面自动翻译」。
3. 页面中的外语内容会在原文旁显示中文译文。
4. 新消息和新帖子通过 `MutationObserver` 自动扫描，无需重复点击。

泰语、日语、韩语、高棉语、缅甸语和老挝语等具有独立文字体系的语言会在本地预筛选后翻译。

英语、印尼语、马来语和菲律宾语都使用拉丁字母，容易与姓名和界面文字混淆，因此默认不自动扫描。需要时在「API 设置」中开启「自动翻译拉丁字母语言」。

### 生成外语回复

1. 点击网页右下角的「译」按钮，打开 PolyChat 面板。
2. 选择目标语言和语气。
3. 输入中文草稿。
4. 点击「润色并翻译」。
5. 检查译文后选择「复制译文」或「填入聊天框」。
6. 最终发送由用户自己完成。

如果要使用「填入聊天框」，请先点击一次 Facebook 聊天输入框，让扩展记住目标位置。

## 泰语语气提醒

泰语礼貌词与说话者身份有关：

- 女性常用：`ค่ะ`、`นะคะ`
- 男性常用：`ครับ`、`นะครับ`

建议在「品牌或角色语气补充」中写明长期使用的身份、角色口吻和需要保留的专有名词。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 在本机保存 API 设置和用户偏好 |
| `activeTab` | 从工具栏弹窗打开当前页面中的回复助手 |
| Facebook / Messenger 内容脚本 | 识别页面消息并插入本地 UI 和译文 |
| 可选 API 域名权限 | 只允许后台脚本请求用户配置的 API 域名 |

扩展没有自动发送消息、读取浏览器历史、访问文件或控制其他网站的权限。

## 当前限制

- 当前只注入 Facebook 和 Messenger，其他网站需要在 `manifest.json` 中增加匹配规则并验证页面结构。
- Facebook 会持续调整 DOM；自动翻译使用语义属性和保守筛选，但仍可能漏掉或误判部分短句。
- 拉丁字母语言的自动识别只能作为预筛选，最终语言判断由模型完成。
- 扩展没有把 API Key 加密；它由浏览器本地扩展存储保护。不要在公共或共享浏览器中保存敏感密钥。
- 机器翻译不能保证敬语、俚语、双关语和关系距离完全准确，发送前必须人工检查。

## 隐私

只有进入翻译队列的文字和用户主动提交的中文草稿会发送到所配置的 API。请不要翻译密码、支付信息、身份号码或其他不应交给该 API 的敏感内容。
