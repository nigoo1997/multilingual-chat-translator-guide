# 多语言聊天翻译助手（Edge / Chrome 版）

基于「沉浸式翻译」扩展的社交媒体双向翻译配置指南，支持中文与东南亚常用语言、日语、韩语和英语互译。

- 阅读：自动把 Facebook 动态、评论和 Messenger 聊天翻译成中文，并保留原文。
- 回复：在浏览器侧边栏输入中文，生成目标语言，复制后粘贴到聊天框。
- 安全：不会自动发送消息，最终内容由用户检查、粘贴并手动发送。

> 本项目不是独立开发的浏览器扩展，而是一套基于现有扩展的配置与使用流程。下载本仓库不会自动安装翻译功能。

## 浏览器版本

- [Google Chrome 配置指南](./CHROME.md)

## 工作方式

| 场景 | 输入 | 输出 | 操作方式 |
| --- | --- | --- | --- |
| 阅读动态、评论和聊天 | 外语 | 原文 + 中文译文 | 页面内自动完成 |
| 编写回复 | 中文草稿 | 所选目标语言 | 浏览器侧边栏生成并复制 |
| 发送消息 | 翻译结果 | 社交平台消息 | 用户检查后手动发送 |

```text
对方发送外语
    ↓
页面自动显示中文译文
    ↓
在右侧翻译栏输入中文回复
    ↓
选择泰语、越南语、日语等目标语言
    ↓
生成、检查并复制
    ↓
粘贴到聊天框并手动发送
```

## 通用配置

### 阅读外语内容

在需要翻译的网站打开「沉浸式翻译」：

- 原文语言：自动检测
- 目标语言：简体中文
- 当前网站翻译设置：自动翻译
- 译文偏好：双语对照
- 强制翻译所有内容：开启
- 直接翻译网页侧边导航：开启
- 隐私保护：开启

对于 Facebook 这类混合多种语言、动态加载内容的页面，「自动检测」和「强制翻译所有内容」尤其重要。

### 生成外语回复

1. 打开扩展侧边栏中的「文本」翻译。
2. 输入语言选择「简体中文」。
3. 输出语言选择当前联系人使用的语言。
4. 输入完整的中文草稿。
5. 点击「翻译」。
6. 选择最自然的结果，点击旁边的复制图标。
7. 粘贴到聊天框，检查后手动发送。

如果目标语言旁边出现数字，表示同时选择了多个输出语言。只需要一种译文时，可以取消其他语言。

## 提高自然度

- 中文草稿要写清楚对象、语气和上下文。
- 人名、品牌名、活动名和专有名词建议保留原文。
- 私聊可以注明“自然、亲切”；客服沟通可以注明“礼貌、简洁”。
- 机器翻译可能误判性别、敬语和关系距离，发送前需要人工检查。
- 重要或敏感消息应由熟悉目标语言的人复核。

### 泰语特别提醒

- 女性常用礼貌词：`ค่ะ`、`นะคะ`
- 男性常用礼貌词：`ครับ`、`นะครับ`

### 日语和韩语特别提醒

- 日语需要检查敬体、简体以及对方称呼。
- 韩语需要检查敬语等级，不要只看字面翻译。

### 英语特别提醒

- 可以在中文草稿中注明需要正式、自然或轻松语气。
- 商务沟通要检查日期、金额、承诺和专有名词。

## 隐私与安全

- 输入侧边栏的文本会交给所选翻译服务处理，不要输入密码、支付信息或其他敏感资料。
- 不要把包含私人聊天、头像、昵称或群组成员信息的原始截图上传到公开仓库。
- 教程截图应对头像、姓名、消息内容和通知数量进行打码。
- 本流程不会自动点击聊天平台的发送按钮。

## 常见问题

### 聊天内容没有自动翻译

检查当前网站是否设置为「自动翻译」，确认目标语言为简体中文，并开启「强制翻译所有内容」。动态消息未翻译时，可重新打开聊天窗口或刷新页面。

### 侧边栏不见了

点击扩展图标，进入「更多功能」，选择「开启侧边栏」。如果没有该选项，请更新浏览器和扩展；也可以暂时使用扩展中的「文本翻译」页面。

### 多语言混在同一页面

保留原文语言为「自动检测」。个别短句、缩写、网络用语或混合语言可能识别错误，需要手动选择源语言重试。
